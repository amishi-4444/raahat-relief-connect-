# Raahat — Jammu Relief Connect

A responsive, front-end-only hackathon prototype for a location-based community relief and volunteer coordination service focused on Jammu.

## Run it
1. Unzip `JammuReliefConnect.zip`.
2. Open `index.html` in a modern browser. No build tools or installation are required.
3. For a public demo, host the folder on GitHub Pages, Netlify, or another static host.

## What's included
- Landing page with Jammu-focused identity and illustrated map
- Assistance request form with type, area, priority, and details
- Searchable/filterable fictional volunteer cards
- Area coverage concept and workflow explainer
- Responsive desktop/mobile layout
- Request preview, contact modal, and clear/reset interactions

## Important prototype boundaries
- All volunteer names, availability, distances, and map markers are fictional sample data.
- Form submission is local-only: it does not send/store the request or notify anyone.
- No real-time GPS, map API, database, authentication, volunteer verification, or dispatch integration is included.
- Do not collect or publish real people's phone numbers or sensitive details in this demo.
- For immediate danger in India, users should call 112; this prototype is not an emergency service.

## Suggested next steps for a production version
1. Backend/API and database for requests, volunteer profiles, availability, and status updates.
2. Verified volunteer onboarding and identity checks; role-based admin/coordinator dashboard.
3. Geospatial matching with explicit location consent and distance estimates from a mapping provider.
4. Request privacy, consent, retention limits, abuse reporting, audit trails, and encryption.
5. Trusted coordination with official emergency services and verified shelter/road-status feeds.
